# ZeroShot Udon UI

VRChat ワールド用の UI ツールキットです。ボタンやスライダーなどの部品を置くだけで、見た目の揃った UI を作れます。

- PC と Quest（Android）の両方で動きます。
- 形はすべてシェーダーで描くので、画像素材が要らず、拡大しても輪郭がぼやけません。
- 部品の操作は、あなたの Udon（UdonSharp）にイベントで伝わります。
- コードからも UI を組み立てられます。AI エージェントに UI を作らせる場合は、[AI エージェント向け利用ガイド](Documentation~/AIGuide.md)を読ませてください。

フォントなどの既製品を除き、このツールキットは 100% 生成 AI（Claude）が作っています。

## 動作環境

| 項目 | 版 |
|---|---|
| Unity | 2022.3 |
| VRChat SDK - Worlds | 3.10.5 以降（UdonSharp を含む） |

## 導入

VRChat Creator Companion（VCC）から導入します。

1. 配布元の GitHub リポジトリを開き、導入ページへ進みます。リポジトリのトップページの右側、「About」の欄にリンクがあります。
2. 導入ページの「VCC に追加」を押します。VCC が開くので、追加を承認します。
3. VCC でプロジェクトの管理画面を開き、「ZeroShot Udon UI」を導入します。

更新するときも、VCC のプロジェクトの管理画面から行います。

導入すると、`Packages/com.helkya.zeroshotudonui/` にツールキット本体が入ります。**このフォルダの中身は書き換えないでください。** 更新のたびに、丸ごと新しい版に置き換わります。

## 最初の UI を置く

1. Hierarchy の何もないところを右クリックし、`ZeroShot Udon UI > ウィンドウ` を選びます。シーンビューで見ている場所に、ウィンドウが置かれます。
2. 置かれたウィンドウを右クリックし、`ZeroShot Udon UI > 設定行` などを選びます。部品はウィンドウの中に、上から順に並びます。
3. 設定行を右クリックして `トグルスイッチ` などを選ぶと、行の右端に置かれます。

初めて使うときに、「TextMeshPro の基本リソースを取り込みます」などの案内が出ることがあります。案内に従い、処理が終わってからもう一度同じ操作をしてください。

全部品の見本は、メニューの `Tools > ZeroShot Udon UI > デモシーンを生成` で作れます。シーンは `Assets/ZeroShotUdonUI/Demo/` に保存されます。

各部品の詳しい説明は、[部品リファレンス](Documentation~/Reference.md)にあります。

### 置き方の決まり

- UI の大きさの単位は mm です（Canvas の 1 単位 = 1mm）。
- ウィンドウと Canvas は、別の Canvas の中に置かないでください。縮尺が二重に掛かり、見えない大きさになります。
- Canvas のレイヤーは `Default` のままにしてください。`UI` レイヤーにすると、VRChat のメニューを開いている間しか操作できません。

## 操作を受け取る

部品が操作されると、あなたの Udon にイベントが送られます。設定するのは、部品の Inspector にある次の 2 欄です。

| 欄 | 入れるもの |
|---|---|
| Event Target（通知先） | あなたのスクリプトを付けたオブジェクト |
| Event Name（イベント名） | 呼び出したい `public` メソッドの名前 |

スクリプトの例です。トグルスイッチでランプを点けたり消したりします。

```csharp
using UdonSharp;
using UnityEngine;
using ZeroShotUdonUI;

public class LampSwitch : UdonSharpBehaviour
{
    public ToggleSwitch toggle;   // シーンに置いたトグルスイッチ
    public GameObject lamp;

    public void OnLampToggled()   // トグルスイッチの Event Name に書く名前
    {
        lamp.SetActive(toggle.IsOn);
    }
}
```

- イベントは「変わった」ことだけを伝えます。値は、`toggle.IsOn` のように部品から読みます。
- スクリプトから値を変えるときは、`SetValue` を使います。通知を出さずに変えたいときは、`SetValueWithoutNotify` を使います。
- **あなたのスクリプトは、ウィンドウの外のオブジェクトに付けてください。** ウィンドウの中に付けると、ウィンドウを最初に開くまで、スクリプトの初期化（`Start`）が実行されません。
- ウィンドウの開閉は、スクリプトを書かなくても設定できます。ボタンの Event Target にウィンドウを、Event Name に `Open`、`Close`、`ToggleOpen` のどれかを入れます。
- 操作の結果は、初期の設定では、操作した本人にだけ反映されます。全員に反映したい場合は、次の「全員で同じ値にする」を見てください。

メニューの `Tools > ZeroShot Udon UI > サンプル生成` で、設定ウィンドウとスクリプトを組み合わせた見本を置けます。

## 全員で同じ値にする（同期）

部品を右クリックし、`ZeroShot Udon UI > 選択中の部品を同期する` を選ぶと、その部品の操作の結果が、インスタンス内の全員に反映されます。

- 同期できるのは、トグルスイッチ、チェックボックス、スライダー、数値ステッパー、選択ボタン群、ドロップダウン、ボタンです。
- ほかの人の操作で値が変わったときも、あなたのスクリプトに通知が届きます。「値が変わったら、こうする」というスクリプトを 1 つ書けば、全員の手元で同じ処理が動きます。
- 後から入ってきた人にも、今の値が届きます（通知も届きます）。誰も操作していなければ、各自の初期値のままです。
- ボタンを同期すると、押したときの処理が、全員の手元で動きます。後から入ってきた人には届きません。
- ウィンドウを閉じていても、同期は止まりません。
- 同期を有効にすると、シーンの最上位に `ZS Sync` というオブジェクトができます。**このオブジェクトは、消したり無効にしたりしないでください。** 同期が止まります。

デモシーン（`Tools > ZeroShot Udon UI > デモシーンを生成`）の左手前にある「Sync」のパネルで、同期の動きを試せます。見本のスクリプトは `Samples/SyncDemoController.cs` です。

詳しくは、[部品リファレンス](Documentation~/Reference.md)の「同期」を見てください。

## うまく動かないとき

メニューの `Tools > ZeroShot Udon UI > 設定チェック` を開くと、開いているシーンを調べて、設定の誤りを一覧にします。

- VRChat で操作できない原因（Canvas のレイヤー、当たり判定など）
- イベント名の打ち間違い（通知先のスクリプトに、その名前のメソッドが無い）
- タブの見出しとページの数の食い違い、など

行を押すと、問題のあるオブジェクトが選ばれます。自動で直せるものには、「直す」ボタンが付きます。VRChat にアップロードする前に、一度開いてみることを勧めます。

## テーマ（色と形）を変える

メニューの `Tools > ZeroShot Udon UI > テーマ設定` を開きます。アクセント色、パネルの色、角丸の半径などを変えると、シーン上のすべての UI にすぐ反映されます。

**色は、この画面から変えてください。** パッケージの中のマテリアルを直接書き換えた場合、その値はツールキットを更新すると失われます。

パネル（ウィンドウや確認ダイアログを含む）と、ドロップダウンの一覧には、うっすらと影が付きます。影の濃さとぼかしの幅も、テーマ設定で変えられます。濃さを 0 にすると、影が消えます。

文字の色とアイコンの色は、テーマの対象外です。部品ごとに Inspector で変えます。

## 日本語を表示する

導入した直後は、英数字と記号だけが表示できます。日本語を使うときは、次の操作をします。

1. メニューの `Tools > ZeroShot Udon UI > フォント設定` を開きます。
2. 「Noto Sans JP をダウンロード」を押します。フォント（約 4.5MB）とライセンス文書が、`Assets/ZeroShotUdonUI/Fonts/` に保存されます。
3. 「元のフォント」が `NotoSansJP-Medium` になっていることを確かめ、「生成」を押します。

これで、かな、英数字、記号と、常用漢字 2,136 字が表示できます。

### 収録されていない文字

- 常用漢字に無い字（例：薔薇、檸檬）は、Unity のエディタ上では □ になります。VRChat の中では、VRChat が持つフォントで補われて表示されます。
- この補完が働くには、プロジェクト設定の TextMeshPro の「Fallback Font Assets」が空である必要があります（`Edit > Project Settings > TextMesh Pro > Settings`）。新しいプロジェクトでは、最初から空です。
- エディタ上でも表示したい字は、「フォント設定」の「追加で収録する文字」に書いてから、生成し直します。

### フォントを変える

「元のフォント」に別のフォントファイル（ttf か otf）を指定して生成し直すと、すべての UI のフォントが切り替わります。

### フォントのライセンス

ツールキットには、フォントを同梱していません。生成したフォントアセットには、元のフォントの文字の形が含まれます。そのため、ワールドを公開するときは、元のフォントのライセンスに従ってください。

Noto Sans JP のライセンスは、SIL Open Font License 1.1 です。ワールドの中か説明欄に、フォントの名前とライセンスを記載することを勧めます。記載の例です。

```
Font: Noto Sans JP (c) 2014-2021 Adobe, licensed under the SIL Open Font License 1.1
```

詳しくは、`Editor/Fonts/THIRD-PARTY-NOTICES.txt` を読んでください。

## 更新したときの動き

VCC でツールキットを更新すると、パッケージのフォルダは丸ごと新しい版に置き換わります。

- **テーマ設定で変えた値と、生成したフォントは、自動で元に戻ります。** 設定の控えを `Assets/ZeroShotUdonUI/Settings.json` に保存しているためです。更新後の最初の起動では、フォントの作り直しに少し時間がかかります。
- シーンに置いた UI は、そのまま残ります。新しい版でプレハブが変わった場合は、置いた UI にも反映されます。
- `Assets/ZeroShotUdonUI/` には、取得したフォント、設定の控え、生成したデモシーンが入っています。このフォルダは消さないでください。
