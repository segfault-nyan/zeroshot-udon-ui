# 変更履歴

このファイルには、版ごとの変更内容を記録します。版の番号は[セマンティック バージョニング](https://semver.org/lang/ja/)に従います。`1.0.0` より前の版では、互換性のない変更が入ることがあります。

## 0.2.0（未公開）

### 追加

- チェックボックス
- 数値ステッパー（＋と－のボタンで数値を増減する）
- 進捗バー
- ドロップダウン（一覧を開いて 1 つを選ぶ）
- タブ（見出しを押してページを切り替える）
- スクロール領域（枠に収まらない内容をスクロールして見る）
- 確認ダイアログ（「はい / いいえ」を尋ねる小窓）
- 設定チェック（シーンを調べて、VRChat で操作できない原因や、イベント名の打ち間違いなどを見つける）

### 変更

- 文書の説明を訂正した。「一度も表示されていないオブジェクトのスクリプトは、イベントを受け取れない」と書いていたが、実際には受け取れる。実行されないのは、初期化（`Start`）と、VRChat が呼び出すイベントだけ。最初から閉じているウィンドウの中の部品も、スクリプトから読み書きできる。

### 修正

- 選択ボタン群の中のオブジェクトに、重ならない名前を付けた。`0.1.0` には、ツールキットの更新でプレハブが変わったときに、選択肢の文字が初期値に戻ることがある問題があった。

### 更新するときの注意

- `0.1.0` で置いた選択ボタン群は、この版に更新すると、選択肢の文字が初期値（Option 1、Option 2）に戻ります。上の修正で、プレハブの中の名前を変えたためです。お手数ですが、文字を入れ直してください。この版より後の更新では、戻りません。

## 0.1.0（2026-10-12）

最初の版です。

### 部品

- ボタン（主、副、枠線のみ、アイコンのみ）
- トグルスイッチ
- スライダー（現在値の表示つき）
- 選択ボタン群
- ラベル（見出し、本文、補足）
- アイコン（10 種類。画像を使わず、シェーダーで描く）

### 容れ物と配置

- ウィンドウ（タイトルと閉じるボタンつき。Udon から開閉できる）
- パネル、設定行、自動配置（縦、横）
- VRChat で操作できる設定を済ませた Canvas

### 制作支援

- Hierarchy の右クリックメニューから部品を追加する
- コードから UI を組み立てる関数群（`UIBuilder`）
- テーマ設定の画面（色、角丸、枠線をまとめて変える）
- フォント設定の画面（日本語フォントの取得と、フォントアセットの生成）
- デモシーンとサンプルの生成
- テーマとフォントの設定を、ツールキットの更新後に自動で元に戻す
