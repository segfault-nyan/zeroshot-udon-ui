# 部品リファレンス

ZeroShot Udon UI の各部品について、設定項目、イベント、スクリプトから使える操作をまとめた文書です。導入と基本の使い方は、[README](../README.md) にあります。

## 共通事項

### 単位と大きさ

UI の大きさと位置の単位は mm です。Canvas の縮尺が 0.001 なので、Canvas の 1 単位が 1mm になります。幅 600 のウィンドウは、ワールドの中で 60cm です。

### 追加の方法

部品を追加する方法は 3 つあります。どれも同じプレハブを置きます。

| 方法 | 向いている場面 |
|---|---|
| Hierarchy の右クリックメニュー `ZeroShot Udon UI > …` | Unity の画面で UI を組む |
| プレハブを直接置く（`Packages/com.helkya.zeroshotudonui/Runtime/Prefabs/`） | 同上 |
| エディタ用のコードから `UIBuilder` の関数を呼ぶ | コードで UI を組む（[AI エージェント向け利用ガイド](AIGuide.md)） |

### イベント

操作できる部品（ボタン、トグルスイッチ、スライダー、選択ボタン群、ウィンドウ）は、Inspector に次の 2 欄を持ちます。

| 欄 | 入れるもの |
|---|---|
| Event Target | 通知先。あなたの UdonSharp スクリプトを付けたオブジェクト |
| Event Name | 通知先で呼び出す `public` メソッドの名前 |

- 部品が操作されると、通知先のメソッドが呼ばれます。どちらかの欄が空なら、何も送りません。
- イベントは「変わった」ことだけを伝えます。値は、部品のプロパティから読みます。
- 通知先のスクリプトは、常に有効なオブジェクトに付けてください。VRChat では、一度も有効になっていないオブジェクトの Udon は、イベントを受け取れません。
- 部品のスクリプトにある、名前が `_` で始まるメソッド（`_OnClick` など）は、部品の内部で使うものです。呼び出さないでください。

### 値の読み書き

値を持つ部品は、同じ形の操作を持ちます。スクリプトでは、`using ZeroShotUdonUI;` を書いて使います。

| 操作 | 動き |
|---|---|
| 値のプロパティ（`IsOn`、`Value`、`SelectedIndex`） | 現在の値を読む |
| `SetValue(値)` | 値を変える。実際に変わったときだけ、通知先にイベントを送る |
| `SetValueWithoutNotify(値)` | 通知を出さずに値を変える。初期化や、同期で受け取った値の反映に使う |

### 同期

部品は同期しません。操作の結果は、操作した本人にだけ反映されます。インスタンスの全員に反映したい場合は、通知先のスクリプトで同期し、受け取った側で `SetValueWithoutNotify` を呼んでください。

## 操作部品

### ボタン

押すと、通知先にイベントを送ります。スクリプトは `ButtonControl` です。

| 種類 | 見た目 | 使いどころ |
|---|---|---|
| 主 | アクセント色の塗り | その画面でいちばん大事な操作 |
| 副 | 灰色の塗り | そのほかの操作 |
| 枠線のみ | アクセント色の枠線 | 目立たせたくない操作（閉じる、キャンセルなど） |
| アイコン | 灰色の丸にアイコン | 閉じる、追加など、形で伝わる操作 |

- 文字は、子の `Label` で変えます。
- アイコンボタンのアイコンは、子の `Icon` で変えます（[アイコン](#アイコン)）。
- 一時的に押せなくするには、uGUI の `Button` の `Interactable` を外します。

### トグルスイッチ

オンとオフを切り替えます。スクリプトは `ToggleSwitch` です。

| 操作 | 型 | 内容 |
|---|---|---|
| `IsOn` | `bool` | オンなら `true` |
| `SetValue(bool)` | | 状態を変える |
| `SetValueWithoutNotify(bool)` | | 通知を出さずに状態を変える |

- 最初の状態は、uGUI の `Toggle` の `Is On` で決めます。Inspector で変えた場合、見た目は再生したときに切り替わります。
- イベントは、状態が切り替わるたびに送られます。

### スライダー

つまみを動かして数値を決めます。右端に現在値を表示します。スクリプトは `SliderControl` です。

| 操作 | 型 | 内容 |
|---|---|---|
| `Value` | `float` | 現在の値 |
| `SetValue(float)` | | 値を変える。範囲外の値は、範囲内に丸められる |
| `SetValueWithoutNotify(float)` | | 通知を出さずに値を変える |

| 設定項目 | 内容 |
|---|---|
| uGUI の `Slider` の `Min Value`、`Max Value`、`Value` | 範囲と最初の値 |
| uGUI の `Slider` の `Whole Numbers` | 整数だけにする |
| `Value Format` | 現在値の表示形式。`0%` は 0.5 を「50%」、`0.00` は「0.50」、`0` は整数で表示する |
| `Value Label` | 現在値を表示するテキスト。表示が要らなければ、子の `Value Label` を無効にする |

- イベントは、つまみを動かしている間、値が変わるたびに送られます。

### 選択ボタン群

横に並んだ選択肢から 1 つを選びます。スクリプトは `SegmentedControl` です。

| 操作 | 型 | 内容 |
|---|---|---|
| `SelectedIndex` | `int` | 選ばれている選択肢の番号。左端が 0 |
| `Count` | `int` | 選択肢の数 |
| `SetValue(int)` | | 選択を変える。範囲外の番号は無視する |
| `SetValueWithoutNotify(int)` | | 通知を出さずに選択を変える |

- プレハブの選択肢は 2 つです。増やすときは、子の `Segment 2` を複製します。名前は `Segment 3` のように、重ならないものにしてください。
- 選択肢の文字は、それぞれの子の `Label` で変えます。
- 最初に選ばれている選択肢は、それぞれの uGUI の `Toggle` の `Is On` で決めます。オンにするのは 1 つだけにしてください。
- イベントは、選択が変わるたびに 1 回送られます。

## 表示部品

### ラベル

文字を表示します。TextMeshPro のテキストで、専用のスクリプトはありません。

| 種類 | 文字の大きさ | 色 | 使いどころ |
|---|---|---|---|
| 見出し | 36、太字 | 白に近い色 | 画面やまとまりの題名 |
| 本文 | 24 | 白に近い色 | 説明、項目名 |
| 補足 | 18 | 灰色 | 注記、区切りの小見出し |

- すべてのラベルは、共通のフォントアセット `ZS_Font` を使います。フォントの変え方は、README の「日本語を表示する」にあります。
- 色と大きさは、部品ごとに Inspector で変えられます。テーマ設定の対象ではありません。

### アイコン

線で描いたアイコンを表示します。画像は使わず、シェーダーで描きます。

| 番号 | 名前 | 形 |
|---|---|---|
| 0 | `Close` | × |
| 1 | `Check` | チェック |
| 2 | `Plus` | ＋ |
| 3 | `Minus` | － |
| 4 | `ChevronUp` | 上向きの矢印の先 |
| 5 | `ChevronDown` | 下向きの矢印の先 |
| 6 | `ChevronLeft` | 左向きの矢印の先 |
| 7 | `ChevronRight` | 右向きの矢印の先 |
| 8 | `Menu` | 三本線 |
| 9 | `Info` | 丸に i |

- 種類は、`RawImage` の `UV Rect` の `X` に「番号 × 2」を入れて決めます。`Check` なら 2、`Menu` なら 16 です。`W` と `H` は 1 のままにします。
- Udon から切り替えるときも、同じ値を書き込みます。例：`icon.uvRect = new Rect(2f, 0f, 1f, 1f);`
- 色は、`RawImage` の `Color` で変えます。
- 大きさを変えても、形は崩れません。短辺に合わせた正方形の中に描かれます。

## 容れ物と配置

### ウィンドウ

タイトルと閉じるボタンのついたパネルです。スクリプトは `WindowPanel` です。

```
Window            WindowPanel（開閉のスクリプト）。常に有効
└─ Canvas         閉じると、ここから下が無効になる
   ├─ Panel       背景
   ├─ Title       タイトルの文字
   ├─ Close Button
   └─ Content     部品を置く場所（縦の自動配置）
```

| 操作 | 型 | 内容 |
|---|---|---|
| `IsOpen` | `bool` | 開いていれば `true` |
| `Open()` | | 開く |
| `Close()` | | 閉じる |
| `ToggleOpen()` | | 開いていれば閉じ、閉じていれば開く |

- `Open`、`Close`、`ToggleOpen` は、ボタンの Event Name にそのまま書けます。ボタンの Event Target にはウィンドウを指定します。スクリプトを書かずに開閉できます。
- 閉じている間は、当たり判定も無効になります。見えないウィンドウが、レーザーを遮ることはありません。
- 開閉が変わると、ウィンドウの通知先にイベントを送ります。
- 大きさは、子の `Canvas` の `Width` と `Height` で変えます。あわせて、`Box Collider` の `Size` の X と Y も同じ値にしてください。当たり判定の大きさです。
- 開くためのボタンは、ウィンドウの外（別の Canvas）に置いてください。ウィンドウの中のボタンは、閉じている間は押せません。
- 最初から閉じた状態で始める使い方（子の `Canvas` を無効にしておく）は、動作を確認していません。VRChat では、一度も有効になっていないオブジェクトの Udon が動かないため、開く前に中の部品の値を読み書きすると、失敗するおそれがあります。

### Canvas

VRChat で操作できる設定を済ませた、ワールド空間の Canvas です。メニューの「Canvas とパネル」は、これに背景のパネルと `Content`（縦の自動配置）を付けたものを置きます。

- 大きさを変えるときは、`Width`、`Height` と、`Box Collider` の `Size` の X、Y を同じ値にします。
- レイヤーは `Default` のままにします。
- Canvas の中に、別の Canvas やウィンドウを置かないでください。

### パネル

部品を載せる背景の板です。親いっぱいに広がります。

### 自動配置

中に置いた部品を、等間隔で並べる枠です。

| 種類 | 並べ方 |
|---|---|
| 縦 | 上から順に並べる。幅の扱いは下の表のとおり |
| 横 | 子の大きさを変えずに、左から順に並べる |

縦の自動配置の中では、部品の種類によって幅の扱いが変わります。高さは、部品の値がそのまま使われます。

| 幅の扱い | 対象 |
|---|---|
| 幅を保ち、左に寄せる | ボタン、アイコンボタン、トグルスイッチ、アイコン |
| 枠の幅いっぱいに広がる | 設定行、スライダー、選択ボタン群、ラベル、自動配置 |

- 幅を保つ部品の幅を変えるときは、`Layout Element` の `Preferred Width` を変えます。
- ツールキット以外のオブジェクトを縦の自動配置に入れると、幅が 0 になります。入れる場合は、`Layout Element` を付けて幅を指定します。
- ウィンドウと「Canvas とパネル」の `Content` は、縦の自動配置です。高さを超えた分は、下にはみ出します。

### 設定行

左に項目名、右に操作部品を置く行です。設定画面の基本の単位です。

- 項目名は、子の `Label` で変えます。
- 操作部品は、子の `Control` の中に置きます。設定行を選んでメニューから操作部品を追加すると、右端に寄せて置かれます。

## メニューの一覧

`Tools > ZeroShot Udon UI` にあります。

| メニュー | 内容 |
|---|---|
| テーマ設定 | アクセント色、パネルの色、角丸、枠線をまとめて変える |
| フォント設定 | 日本語フォントの取得と、共通のフォントアセットの生成 |
| サンプル生成 | 設定ウィンドウとスクリプトの見本を、開いているシーンに置く |
| デモシーンを生成 | 全部品を並べた見本のシーンを作る |
| プレハブを生成 | プレハブを初期の状態に作り直す。ツールキットの開発用で、通常は使わない |
