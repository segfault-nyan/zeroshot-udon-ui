# 部品リファレンス

ZeroShot Udon UI の各部品について、設定項目、イベント、スクリプトから使える操作をまとめた文書です。導入と基本の使い方は、[README](../README.md) にあります。

## 共通事項

### 単位と大きさ

UI の大きさと位置の単位は mm です。Canvas の縮尺が 0.001 なので、Canvas の 1 単位が 1mm になります。幅 600 のウィンドウは、ワールドの中で 60cm です。

### 追加の方法

部品を追加する方法は 3 つあります。どれも同じプレハブを置きます。

| 方法 | 向いている場面 |
|---|---|
| Hierarchy の右クリックメニュー `ZeroShot Udon UI > …` | Unity の画面で UI を組む |
| プレハブを直接置く（`Packages/com.helkya.zeroshotudonui/Runtime/Prefabs/`） | 同上 |
| エディタ用のコードから `UIBuilder` の関数を呼ぶ | コードで UI を組む（[AI エージェント向け利用ガイド](AIGuide.md)） |

### イベント

操作できる部品（ボタン、トグルスイッチ、チェックボックス、スライダー、数値ステッパー、選択ボタン群、ドロップダウン、ウィンドウ、タブ、確認ダイアログ）は、Inspector に次の 2 欄を持ちます。

| 欄 | 入れるもの |
|---|---|
| Event Target | 通知先。あなたの UdonSharp スクリプトを付けたオブジェクト |
| Event Name | 通知先で呼び出す `public` メソッドの名前 |

- 部品が操作されると、通知先のメソッドが呼ばれます。どちらかの欄が空なら、何も送りません。
- イベントは「変わった」ことだけを伝えます。値は、部品のプロパティから読みます。
- 通知先のスクリプトは、常に有効なオブジェクトに付けることを勧めます。一度も有効になっていないオブジェクトのスクリプトは、通知は受け取れますが、初期化（`Start`）と、VRChat が呼び出すイベント（`OnPlayerJoined` など）が、最初に有効になるまで実行されません。
- 部品のスクリプトにある、名前が `_` で始まるメソッド（`_OnClick` など）は、部品の内部で使うものです。呼び出さないでください。

### 値の読み書き

値を持つ部品は、同じ形の操作を持ちます。スクリプトでは、`using ZeroShotUdonUI;` を書いて使います。

| 操作 | 動き |
|---|---|
| 値のプロパティ（`IsOn`、`Value`、`SelectedIndex`） | 現在の値を読む |
| `SetValue(値)` | 値を変える。実際に変わったときだけ、通知先にイベントを送る |
| `SetValueWithoutNotify(値)` | 通知を出さずに値を変える。初期化や、同期で受け取った値の反映に使う |

### 同期

初期の設定では、部品は同期しません。操作の結果は、操作した本人にだけ反映されます。部品ごとに同期を有効にすると、インスタンス内の全員に反映されます。

| 部品 | 同期するもの |
|---|---|
| トグルスイッチ、チェックボックス | オン・オフ |
| スライダー、数値ステッパー | 値 |
| 選択ボタン群、ドロップダウン | 選ばれている番号 |
| ボタン | 押されたという出来事（全員の手元で、通知先のイベントが動く） |

ウィンドウ、確認ダイアログ、タブ、進捗バーは、同期に対応していません。画面の開閉やページの切り替えは、人ごとの操作として扱います。

**有効にする方法**

- Hierarchy で部品を右クリックし、`ZeroShot Udon UI > 選択中の部品を同期する`。戻すときは「同期しない」。
- コードからは、`UIBuilder.SetSynced(部品, true)`。

**動き**

| 場面 | 動き |
|---|---|
| 誰かが操作した | その人が値を送り、全員の部品が同じ値になる。全員の手元で、通知先にイベントが送られる |
| スクリプトから `SetValue` を呼んだ | 操作と同じ。呼んだ人が値を送る |
| スクリプトから `SetValueWithoutNotify` を呼んだ | 手元だけで値が変わる。ほかの人には送らない |
| 後から入ってきた | 今の値が届き、通知も送られる。誰も操作していなければ、各自の初期値のまま |
| ウィンドウを閉じている、タブで別のページを見ている | 同期は止まらない。閉じている部品にも、値と通知が届く |
| 何人かが同時に操作した | 最後に操作した人の値になる |

- 通知を受け取ったスクリプトの側では、自分の操作か、ほかの人の操作かを区別しません。どちらの場合も、同じ処理が全員の手元で動く、という考え方です。
- スライダーのつまみを動かし続けている間は、VRChat が送信の回数を間引きます。ほかの人の画面では、少し遅れて、段階的に動きます。
- 誰でも操作できます。操作できる人を制限する機能は、まだありません。

**仕組み**

VRChat の同期は、無効になっているオブジェクトでは止まります。そのため、同期の受け持ちを部品から切り離し、部品ごとに「中継役」（`SyncRelay`）を作って、シーンの最上位の `ZS Sync` の下にまとめて置いています。

- **`ZS Sync` と、その中のオブジェクトは、消したり無効にしたりしないでください。** 同期が止まります。
- 部品を消すと、中継役が残ります。設定チェックで見つけて消せます。
- 部品を複製した場合、複製した部品は、元の部品と同じ中継役を指したままになります。設定チェックで見つかるので、「直す」を押すと、複製した部品用の中継役が作られます。

## 操作部品

### ボタン

押すと、通知先にイベントを送ります。スクリプトは `ButtonControl` です。

| 種類 | 見た目 | 使いどころ |
|---|---|---|
| 主 | アクセント色の塗り | その画面でいちばん大事な操作 |
| 副 | 灰色の塗り | そのほかの操作 |
| 枠線のみ | アクセント色の枠線 | 目立たせたくない操作（閉じる、キャンセルなど） |
| アイコン | 灰色の丸にアイコン | 閉じる、追加など、形で伝わる操作 |

- 文字は、子の `Label` で変えます。
- アイコンボタンのアイコンは、子の `Icon` で変えます（[アイコン](#アイコン)）。
- 一時的に押せなくするには、uGUI の `Button` の `Interactable` を外します。

### トグルスイッチ

オンとオフを切り替えます。スクリプトは `ToggleSwitch` です。

| 操作 | 型 | 内容 |
|---|---|---|
| `IsOn` | `bool` | オンなら `true` |
| `SetValue(bool)` | | 状態を変える |
| `SetValueWithoutNotify(bool)` | | 通知を出さずに状態を変える |

- 最初の状態は、uGUI の `Toggle` の `Is On` で決めます。Inspector で変えた場合、見た目は再生したときに切り替わります。
- イベントは、状態が切り替わるたびに送られます。

### チェックボックス

複数の項目を、個別にオン・オフします。左に丸い枠、右に項目名があり、どちらを押しても切り替わります。スクリプトは `CheckboxControl` です。

| 操作 | 型 | 内容 |
|---|---|---|
| `IsOn` | `bool` | オンなら `true` |
| `SetValue(bool)` | | 状態を変える |
| `SetValueWithoutNotify(bool)` | | 通知を出さずに状態を変える |

- 項目名は、子の `Label` で変えます。
- 最初の状態は、uGUI の `Toggle` の `Is On` で決めます。Inspector で変えた場合、見た目は再生したときに切り替わります。
- イベントは、状態が切り替わるたびに送られます。
- トグルスイッチとの使い分け：すぐに効果が出る設定（音を消す、など）にはトグルスイッチ、複数の項目から選ぶ一覧にはチェックボックスが向いています。

### スライダー

つまみを動かして数値を決めます。右端に現在値を表示します。スクリプトは `SliderControl` です。

| 操作 | 型 | 内容 |
|---|---|---|
| `Value` | `float` | 現在の値 |
| `SetValue(float)` | | 値を変える。範囲外の値は、範囲内に丸められる |
| `SetValueWithoutNotify(float)` | | 通知を出さずに値を変える |

| 設定項目 | 内容 |
|---|---|
| uGUI の `Slider` の `Min Value`、`Max Value`、`Value` | 範囲と最初の値 |
| uGUI の `Slider` の `Whole Numbers` | 整数だけにする |
| `Value Format` | 現在値の表示形式。`0%` は 0.5 を「50%」、`0.00` は「0.50」、`0` は整数で表示する |
| `Value Label` | 現在値を表示するテキスト。表示が要らなければ、子の `Value Label` を無効にする |

- イベントは、つまみを動かしている間、値が変わるたびに送られます。

### 数値ステッパー

＋と－のボタンで、数値を一定の幅ずつ増減します。スクリプトは `StepperControl` です。

| 操作 | 型 | 内容 |
|---|---|---|
| `Value` | `float` | 現在の値 |
| `SetValue(float)` | | 値を変える。範囲外の値は、範囲内に丸められる |
| `SetValueWithoutNotify(float)` | | 通知を出さずに値を変える |

| 設定項目 | 内容 |
|---|---|
| `Min Value`、`Max Value` | 範囲 |
| `Step` | ボタンを 1 回押したときに増減する量 |
| `Current Value` | 最初の値 |
| `Value Format` | 現在値の表示形式。`0` は整数、`0.0` は小数第 1 位まで表示する |

- 値は、最小値から数えて `Step` の倍数に丸められます。小数（`Step` が 0.1 など）でも、増減を繰り返して誤差が溜まることはありません。
- 上限か下限に達すると、その側のボタンが押せなくなります。
- 整数として使うときは、`(int)stepper.Value` ではなく `Mathf.RoundToInt(stepper.Value)` で読んでください。
- Inspector で設定項目を変えた場合、表示は再生したときに更新されます。
- イベントは、値が変わるたびに送られます。ボタンを押し続けても、連続では増減しません。

### 選択ボタン群

横に並んだ選択肢から 1 つを選びます。スクリプトは `SegmentedControl` です。

| 操作 | 型 | 内容 |
|---|---|---|
| `SelectedIndex` | `int` | 選ばれている選択肢の番号。左端が 0 |
| `Count` | `int` | 選択肢の数 |
| `SetValue(int)` | | 選択を変える。範囲外の番号は無視する |
| `SetValueWithoutNotify(int)` | | 通知を出さずに選択を変える |

- プレハブの選択肢は 2 つです。増やすときは、子の `Segment 2` を複製します。名前は `Segment 3` のように、重ならないものにしてください。
- 選択肢の文字は、それぞれの子（`Label 1`、`Label 2`）で変えます。
- 最初に選ばれている選択肢は、それぞれの uGUI の `Toggle` の `Is On` で決めます。オンにするのは 1 つだけにしてください。
- イベントは、選択が変わるたびに 1 回送られます。

### ドロップダウン

一覧を開いて、選択肢から 1 つを選びます。開閉と一覧の表示は、TextMeshPro の `TMP_Dropdown` が行います。スクリプトは `DropdownControl` です。

| 操作 | 型 | 内容 |
|---|---|---|
| `SelectedIndex` | `int` | 選ばれている選択肢の番号。いちばん上が 0 |
| `SetValue(int)` | | 選択を変える。範囲外の番号は、範囲内に丸められる |
| `SetValueWithoutNotify(int)` | | 通知を出さずに選択を変える |

| 設定項目 | 内容 |
|---|---|
| `TMP_Dropdown` の `Options` | 選択肢の一覧。文字を足したり、並べ替えたりできる |
| `TMP_Dropdown` の `Value` | 最初に選ばれている選択肢の番号 |

- 選択肢が多いときは、一覧の中でスクロールします。一覧は、ほかの部品より手前に表示されます。
- 一覧が開いているときに、同じ Canvas の別の場所を押すと、一覧が閉じます。
- **スクリプトからは、選択肢の文字を読めません。** 読み書きできるのは番号だけです。文字が要るときは、同じ並びの配列を、あなたのスクリプトの側にも持たせてください。同じ理由で、実行時に選択肢を増やしたり入れ替えたりはできません。
- 選択ボタン群との使い分け：選択肢が 2〜4 個で、すべてを見せておきたいときは選択ボタン群、数が多いときや場所を取りたくないときはドロップダウンが向いています。
- 子の `Template` は、一覧のひな形です。普段は無効になっています。一覧の見た目を変えるときは、この中を書き換えます。
- イベントは、選択が変わるたびに送られます。同じ項目を選び直したときは、送られません。

## 表示部品

### ラベル

文字を表示します。TextMeshPro のテキストで、専用のスクリプトはありません。

| 種類 | 文字の大きさ | 色 | 使いどころ |
|---|---|---|---|
| 見出し | 36、太字 | 白に近い色 | 画面やまとまりの題名 |
| 本文 | 24 | 白に近い色 | 説明、項目名 |
| 補足 | 18 | 灰色 | 注記、区切りの小見出し |

- すべてのラベルは、共通のフォントアセット `ZS_Font` を使います。フォントの変え方は、README の「日本語を表示する」にあります。
- 色と大きさは、部品ごとに Inspector で変えられます。テーマ設定の対象ではありません。

### 進捗バー

進み具合を表示します。操作はできません。右端に現在値を表示します。スクリプトは `ProgressBar` です。

| 操作 | 型 | 内容 |
|---|---|---|
| `Value` | `float` | 現在の値。0 から 1 |
| `SetValue(float)` | | 値を変える。0 から 1 の範囲に丸められる |

| 設定項目 | 内容 |
|---|---|
| uGUI の `Slider` の `Value` | 最初の値 |
| `Value Format` | 現在値の表示形式。`0%` は 0.5 を「50%」と表示する |
| `Value Label` | 現在値を表示するテキスト。表示が要らなければ、子の `Value Label` を無効にする |

- 操作できないので、イベントは送りません。通知先の欄もありません。
- 当たり判定を持たないので、レーザーを遮りません。
- 毎フレーム値を書き込む使い方は、負荷になります。進み具合が変わったときだけ `SetValue` を呼んでください。

### アイコン

線で描いたアイコンを表示します。画像は使わず、シェーダーで描きます。

| 番号 | 名前 | 形 |
|---|---|---|
| 0 | `Close` | × |
| 1 | `Check` | チェック |
| 2 | `Plus` | ＋ |
| 3 | `Minus` | － |
| 4 | `ChevronUp` | 上向きの矢印の先 |
| 5 | `ChevronDown` | 下向きの矢印の先 |
| 6 | `ChevronLeft` | 左向きの矢印の先 |
| 7 | `ChevronRight` | 右向きの矢印の先 |
| 8 | `Menu` | 三本線 |
| 9 | `Info` | 丸に i |

- 種類は、`RawImage` の `UV Rect` の `X` に「番号 × 2」を入れて決めます。`Check` なら 2、`Menu` なら 16 です。`W` と `H` は 1 のままにします。
- Udon から切り替えるときも、同じ値を書き込みます。例：`icon.uvRect = new Rect(2f, 0f, 1f, 1f);`
- 色は、`RawImage` の `Color` で変えます。
- 大きさを変えても、形は崩れません。短辺に合わせた正方形の中に描かれます。

## 容れ物と配置

### ウィンドウ

タイトルと閉じるボタンのついたパネルです。スクリプトは `WindowPanel` です。

```
Window            WindowPanel（開閉のスクリプト）。常に有効
└─ Canvas         閉じると、ここから下が無効になる
   ├─ Panel       背景
   ├─ Title       タイトルの文字
   ├─ Close Button
   └─ Content     部品を置く場所（縦の自動配置）
```

| 操作 | 型 | 内容 |
|---|---|---|
| `IsOpen` | `bool` | 開いていれば `true` |
| `Open()` | | 開く |
| `Close()` | | 閉じる |
| `ToggleOpen()` | | 開いていれば閉じ、閉じていれば開く |

- `Open`、`Close`、`ToggleOpen` は、ボタンの Event Name にそのまま書けます。ボタンの Event Target にはウィンドウを指定します。スクリプトを書かずに開閉できます。
- 閉じている間は、当たり判定も無効になります。見えないウィンドウが、レーザーを遮ることはありません。
- 開閉が変わると、ウィンドウの通知先にイベントを送ります。
- 大きさは、子の `Canvas` の `Width` と `Height` で変えます。あわせて、`Box Collider` の `Size` の X と Y も同じ値にしてください。当たり判定の大きさです。
- 開くためのボタンは、ウィンドウの外（別の Canvas）に置いてください。ウィンドウの中のボタンは、閉じている間は押せません。
- 最初から閉じた状態で始めるには、子の `Canvas` を無効にしておきます。一度も開いていない状態でも、中の部品の値は、スクリプトから読み書きできます（PC の VRChat で確認済み）。

### 確認ダイアログ

「はい / いいえ」を尋ねる小窓です。メッセージと、2 つのボタンを持ちます。スクリプトは `ConfirmDialog` です。

```
Dialog            ConfirmDialog（開閉のスクリプト）。常に有効
└─ Canvas         閉じると、ここから下が無効になる
   ├─ Panel       背景
   ├─ Message     メッセージの文字
   ├─ Confirm Button   「はい」のボタン（右）
   └─ Cancel Button    「いいえ」のボタン（左）
```

| 操作 | 型 | 内容 |
|---|---|---|
| `IsOpen` | `bool` | 開いていれば `true` |
| `Open()` | | 開く |
| `Close()` | | イベントを送らずに閉じる |
| `SetMessage(string)` | | メッセージを変える |

| 設定項目 | 内容 |
|---|---|
| Event Target、Event Name | 「はい」が押されたときの通知先と、呼び出すメソッドの名前 |
| Cancel Event Name | 「いいえ」が押されたときに、同じ通知先で呼び出すメソッドの名前。要らなければ空にする |
| Close On Start | オンなら、ワールドの開始時に閉じる（初期値はオン）。Unity の編集中は表示されたままなので、位置や文字を調整できる |

- どちらのボタンを押しても、ダイアログは閉じます。その後で、通知が送られます。
- 開くには、ボタンの Event Target にダイアログを、Event Name に `Open` を設定します。スクリプトから `dialog.Open()` を呼ぶこともできます。
- 同じダイアログを別の用途に使い回すときは、開く前に `SetMessage` でメッセージを入れ替えます。
- ボタンの文字は、それぞれのボタンの子（`Confirm Label`、`Cancel Label`）で変えます。
- **開いている間も、ほかの UI は操作できます。** ほかの UI の操作を止める仕組みはありません。ダイアログは独立した Canvas なので、関連する UI の少し手前など、見落とされない場所に置いてください。
- 大きさは、ウィンドウと同じく、子の `Canvas` の `Width`、`Height` と、`Box Collider` の `Size` で変えます。

### タブ

見出しを押して、表示するページを切り替えます。スクリプトは `TabView` です。

```
Tabs              TabView
├─ Header         見出し（選択ボタン群）
└─ Pages
   ├─ Page 1      1 つ目の見出しのページ（縦の自動配置）
   └─ Page 2      2 つ目の見出しのページ
```

| 操作 | 型 | 内容 |
|---|---|---|
| `SelectedIndex` | `int` | 表示しているページの番号。左端の見出しが 0 |
| `Count` | `int` | ページの数 |
| `SetValue(int)` | | 表示するページを変える。範囲外の番号は無視する |
| `SetValueWithoutNotify(int)` | | 通知を出さずに、表示するページを変える |

- 部品は、各ページ（`Page 1` など）の中に置きます。ページは縦の自動配置なので、上から順に並びます。
- 見出しの文字は、`Header` の中の `Label 1`、`Label 2` で変えます。
- ページを増やすときは、`Header` の中の選択肢と、`Pages` の中のページを、同じ数になるよう複製します。`Pages` の中の並び順が、見出しの順番に対応します。
- 表示していないページは無効になります。無効なページの中の部品も、スクリプトから値を読み書きできます。
- Unity の編集中に別のページを見たいときは、見たいページを有効に、ほかのページを無効にします。再生すると、見出しで選ばれているページだけが表示されます。
- イベントは、ページが切り替わるたびに送られます。

### スクロール領域

枠に収まらない内容を、スクロールして見ます。専用のスクリプトは無く、uGUI の `Scroll Rect` で動きます。

```
ScrollArea        Scroll Rect
├─ Viewport       表示する範囲。はみ出した部分は描かれない
│  └─ Content     部品を置く場所（縦の自動配置）
└─ Scrollbar      中身が収まっているときは、自動で隠れる
```

- 部品は `Content` の中に置きます。置いた部品の分だけ、`Content` が下に伸びます。
- 動かし方は 2 つあります。内容をつかんで上下に動かすか、右端のスクロールバーのつまみを動かします。
- スクリプトから位置を変えるときは、`Scroll Rect` の `verticalNormalizedPosition` に、1（いちばん上）から 0（いちばん下）の値を入れます。
- 中に置いたスライダーは、つかむとスライダーの側が動きます。スライダーの上では、スクロールできません。
- デスクトップの VRChat では、カーソルがスクロール領域の上にあるときに W、S キーで歩くと、内容も一緒にスクロールします。今の版では、この動きを止めていません。
- 高さは、`Height` で変えます。幅は、縦の自動配置の中では枠の幅いっぱいに広がります。

### Canvas

VRChat で操作できる設定を済ませた、ワールド空間の Canvas です。メニューの「Canvas とパネル」は、これに背景のパネルと `Content`（縦の自動配置）を付けたものを置きます。

- 大きさを変えるときは、`Width`、`Height` と、`Box Collider` の `Size` の X、Y を同じ値にします。
- レイヤーは `Default` のままにします。
- Canvas の中に、別の Canvas、ウィンドウ、確認ダイアログを置かないでください。

### パネル

部品を載せる背景の板です。親いっぱいに広がります。

### 自動配置

中に置いた部品を、等間隔で並べる枠です。

| 種類 | 並べ方 |
|---|---|
| 縦 | 上から順に並べる。幅の扱いは下の表のとおり |
| 横 | 子の大きさを変えずに、左から順に並べる |

縦の自動配置の中では、部品の種類によって幅の扱いが変わります。高さは、部品の値がそのまま使われます。

| 幅の扱い | 対象 |
|---|---|
| 幅を保ち、左に寄せる | ボタン、アイコンボタン、トグルスイッチ、数値ステッパー、ドロップダウン、アイコン |
| 枠の幅いっぱいに広がる | 設定行、チェックボックス、スライダー、選択ボタン群、進捗バー、ラベル、自動配置、タブ、スクロール領域 |

- 幅を保つ部品の幅を変えるときは、`Layout Element` の `Preferred Width` を変えます。
- ツールキット以外のオブジェクトを縦の自動配置に入れると、幅が 0 になります。入れる場合は、`Layout Element` を付けて幅を指定します。
- ウィンドウと「Canvas とパネル」の `Content` は、縦の自動配置です。高さを超えた分は、下にはみ出します。はみ出す量の内容を入れるときは、スクロール領域を使います。

### 設定行

左に項目名、右に操作部品を置く行です。設定画面の基本の単位です。

- 項目名は、子の `Label` で変えます。
- 操作部品は、子の `Control` の中に置きます。設定行を選んでメニューから操作部品を追加すると、右端に寄せて置かれます。

## メニューの一覧

部品の追加と同期の切り替えは、Hierarchy の右クリック（または `GameObject` メニュー）の `ZeroShot Udon UI` にあります。

| メニュー | 内容 |
|---|---|
| ウィンドウ、ボタン（主）など | 部品を追加する |
| 選択中の部品を同期する | 選んでいる部品の同期を有効にする |
| 選択中の部品を同期しない | 選んでいる部品の同期を無効にする |

そのほかのメニューは、`Tools > ZeroShot Udon UI` にあります。

| メニュー | 内容 |
|---|---|
| 設定チェック | 開いているシーンを調べて、VRChat で操作できない原因や、イベント名の打ち間違いなどを一覧にする |
| テーマ設定 | アクセント色、パネルの色、角丸、枠線をまとめて変える |
| フォント設定 | 日本語フォントの取得と、共通のフォントアセットの生成 |
| サンプル生成 | 設定ウィンドウとスクリプトの見本を、開いているシーンに置く |
| デモシーンを生成 | 全部品を並べた見本のシーンを作る |
| プレハブを生成 | プレハブを初期の状態に作り直す。ツールキットの開発用で、通常は使わない |

## 設定チェック

`Tools > ZeroShot Udon UI > 設定チェック` は、開いているシーンを調べて、設定の誤りを一覧にします。ツールキットの部品を含む Canvas だけが対象です。

| 分類 | 調べること | 重さ | 自動で直せる |
|---|---|---|---|
| Canvas | レイヤーが `Default` でない | エラー | ○ |
| Canvas | `VRC Ui Shape` が無い | エラー | ○ |
| Canvas | ワールド空間の設定になっていない | エラー | |
| Canvas | Canvas、ウィンドウ、確認ダイアログが、別の Canvas の中にある | エラー | |
| Canvas | 当たり判定が無い、トリガーでない、大きさが Canvas と合っていない | 警告 | ○ |
| Canvas | 縮尺が、想定（0.001）から大きく外れている | 警告 | |
| イベント | Event Name のメソッドが、通知先のスクリプトに無い、または `public` でない | エラー | |
| イベント | 通知先とイベント名の、片方だけが設定されている | 警告 | |
| イベント | ボタンに、通知先が設定されていない | 情報 | |
| 構成 | タブの見出しの数と、ページの数が合っていない | エラー | |
| 同期 | 同期の中継役が消されている、別の部品とつながっている、同期に対応していない部品に設定されている | エラー | ○ |
| 同期 | 同期の中継役が無効になっている | エラー | ○ |
| 同期 | 使われていない同期の中継役がある | 警告 | ○ |
| 構成 | 選択ボタン群で、最初に選ばれている選択肢が 1 つでない | 警告 | |
| フォント | 日本語の文字があるのに、共通フォントに日本語が入っていない | 警告 | |
| フォント | TextMeshPro の「Fallback Font Assets」が空でない | 警告 | |

- 「エラー」は、VRChat で操作できない、または意図どおりに動かないものです。「警告」は、動くものの問題が起きやすいものです。
- メソッドの有無を調べられるのは、通知先が UdonSharp で書かれている場合だけです。
- 「Console に書き出す」を押すと、結果が Console に出ます。AI エージェントに結果を伝えるときに使えます。
- 見た目の良し悪し（重なり、はみ出しなど）は調べません。
